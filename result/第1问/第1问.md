# 第1问

## 1. 本问任务理解

第1问要求探索 18 个风箱“负压”与对应风箱“温度”之间的关系，并建立只使用风箱负压信息预测对应风箱温度的模型。题面提示南北两侧温度可以合并，因此本问将每个风箱的南侧、北侧温度取算术平均，形成 `1#风箱合并温度` 至 `18#风箱合并温度` 这 18 个统一温度目标。

本问不预测 CO 浓度，也不做负压调控决策。

## 2. 与其他问题的关系

第1问没有对第2问或第3问的硬依赖，只依赖 `附件1.原始数据.xlsx`。本问可向第2问传递统一后的风箱温度字段口径、温度预测结果和模型接口；第2问是否采用这些结果由第2问自行决定。

## 4. 方法与模型

先用相关分析描述一一对应关系：对每个风箱计算当前负压与合并温度的皮尔逊相关系数，并在 0 至 20 个样本滞后内寻找绝对相关最大的滞后。平均当前绝对相关系数为 `0.261`，平均最优滞后绝对相关系数为 `0.298`，最优滞后的中位数为 `2` s，说明负压与温度存在一定动态对应关系。

预测模型采用多输出岭回归：

`T_hat(t) = b + ((X(t) - mean_X) / std_X) * B`

其中 `X(t)` 只由 18 个风箱负压构造，包括当前值、1/3/5/10 个样本滞后值、一阶差分、5 点滚动均值、平方项以及前/中/后段负压均值等特征。模型正则系数在 `[0.0, 0.1, 1.0, 10.0, 100.0, 1000.0]` 中用验证集选择，最终选择 `lambda = 100`。

## 5. 计算过程

1. 读取 `附件1.原始数据.xlsx` 的 `co_levels_comparison_final（1）` 工作表。
2. 提取 `序列`、18 个风箱负压字段、36 个南北侧温度字段。
3. 对每个风箱合并南北温度，生成 18 个预测目标。
4. 生成由负压构造的当前与滞后特征，保留可完整形成 20 s 历史窗口的样本。
5. 按连续时间块随机划分训练集、验证集、测试集，比例约为 70%/15%/15%，使三个集合覆盖不同工况区间，同时避免单点完全随机打乱。
6. 在训练集拟合模型，在验证集选择正则系数，在测试集给出最终误差。
7. 额外做一次“前 70% 训练、后 15% 测试”的时间后段外推压力测试，用于判断跨工况外推风险。
8. 保存预测值、残差、评价指标、模型参数和基础可视化。

最终模型测试集整体结果：MAE = `10.683` ℃，RMSE = `20.110` ℃，R2 = `0.987`。验证集整体结果：MAE = `10.823` ℃，RMSE = `19.572` ℃，R2 = `0.988`。

需要注意，整体 R2 会受到不同风箱温度水平差异较大的影响，因此分风箱 RMSE 和分风箱 R2 更适合判断单个风箱的预测效果。本问将整体指标用于比较模型，把分风箱指标用于定位误差来源。

时间后段外推压力测试的测试集结果为：MAE = `34.321` ℃，RMSE = `194.649` ℃，R2 = `-0.279`。该结果低于连续块随机测试，说明单纯依靠历史前段数据外推到后段工况并不稳定，后续在线使用时应滚动更新或覆盖更多工况样本。
