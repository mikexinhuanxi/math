# 第3问

## 1. 本问任务理解

第3问不再被表述成一个单独替代现场的“低排放潜力评分模型”。更准确地说，第二问模型承担主要 CO 预测器角色；第三问是在该预测器外面增加规划搜索、温度增量联动、工程可执行性保护和滚动控制，形成“预测器 + 规划器”的调控模型。`Q10/Q50/Q90` 可以保留，但三层规划筛选改为 `Q50(P)<=2800`、`Q90(P)<=Q90(P0)` 和 `Pr_pass_like(P)>=θ`；其中 `Pr_pass_like` 表示达标工况相似度/倾向概率，不是真实现场达标概率。`Q10<=2700` 只作为低排放潜力指标，不再作为约束。

- 主模型：300s 后单点 CO 的 `Q05/Q10/Q50/Q90` 达标潜力模型。底层回归器使用 `GradientBoostingRegressor(loss="quantile")` 训练各分位数，近达标/达标倾向分类器使用 `HistGradientBoostingClassifier`；因此这是非线性树提升模型，不是线性回归模型。全局模型用全部样本训练，尾部模型只用 `CO<=3200` 及其达标模板邻域样本训练，并对 `CO<=2800` 加高权重；Q50 最终值采用 `Pr_low` 门控融合，所有分位数预测后统一排序，避免 `Q05>Q10` 或 `Q10>Q50` 的交叉。
- 两级分类器：`Pr_near_like=S(300s后单点CO<=3200)` 和 `Pr_pass_like=S(300s后单点CO<=2800)`；这里的 `S` 是模型给出的工况相似度/倾向分数。若训练集中 `single_point_pass` 正样本数不少于 20，`Pr_pass_like` 进入软筛选，否则只作诊断。
- 工况门控：先判断当前状态是否接近达标工况层；接近时用第二问预测器输出的 Q50/Q90/达标倾向分数进入规划筛选，远离时只输出调节方向，不承诺现场达标。
- 方案生成：先生成候选并标记工程可执行性，再按 `Q50(P)<=2800`、`Q90(P)<=Q90(P0)`、`Pr_pass_like>=θ` 三层筛选和排序；Q10 仅用于描述低排放潜力。本次把方案 B 定为主推荐方案，方案 A 仅作为 Q50 最小化对照，因为方案 A 虽然降低 Q50，但不满足 `Q90(P)<=Q90(P0)` 的风险不恶化要求。

本问不再用 `当前 CO + ΔCO` 作为最终判断。模型输出只作为优化评分的一部分，方案是否真实达标需结合现场复核：

```text
Engineering guardrails:
  optional engineering guardrails, not problem-given mandatory constraints
  |P_i-P_i^0| <= single-box max adjustment
  sum_i |P_i-P_i^0| <= total adjustment budget
  |P_i-P_(i-1)| <= adjacent box difference limit
  |Delta T_i| <= temperature-change guardrail

Objective among feasible candidates:
  layer 1: Q50_point(P) <= 2800
  layer 2: Q90_point(P) <= Q90_point(P0)
  layer 3: Pr_pass_like(P) >= theta
  indicator only: Q10_point(P) <= 2700
  gate: if current state is far from low-emission layer, output direction only
Classifier(P) = [Pr_low, Pr_near_like, Pr_pass_like], with Pr_near_like >= Pr_pass_like
```

## 5. 分层调控响应模型

调控模型重新构造未来预测数据集：每一行用控制时刻 `t` 的 CO 状态、过程变量和负压调节量，预测 `t+300s` 时刻的单点 CO；同时另算 `t+300s` 后 `300` s 窗口 CO 中位数作为稳定性风险诊断。历史 CO 不再删除，而是作为短期状态变量进入模型；训练目标从普通均值 CO 改为分位数 CO。全局模型使用全部样本训练 `Q05/Q10/Q50/Q90`，保证整体稳定；尾部模型只使用 `CO<=3200` 及其达标模板邻域样本训练，并对 `CO<=2800` 加高权重。Q50 采用 `Pr_low` 门控融合：

```text
X(t) = CO状态(t) + 过程变量(t) + 负压调节量(t)
Pr_low = Pr(进入低排放工况层 | X(t))
alpha = f(Pr_low)
Q50_final = (1-alpha) * Q50_global + alpha * Q50_tail
CO_low_extreme = 0.5 * Q05_global + 0.5 * Q05_tail
sort_each_row(Q05, Q10, Q50, Q90)
Pr_near_like = S(CO(t+300s)<=3200 | X(t))
Pr_pass_like = S(CO(t+300s)<=2800 | X(t))
Pr_near_like = max(Pr_near_like_raw, Pr_pass_like_raw)
```

这里的 `Pr_near_like` 和 `Pr_pass_like` 沿用分类器输出的数值形态，但含义应解释为“近达标/达标工况相似度或倾向概率”，不能解释为现场真实达标概率。真实达标仍需以后续 300 s 实测 CO 与连续稳定性复核为准。

本次预测器为 `未来300s Q05/Q10/Q50/Q90达标潜力模型 + 全局/尾部融合 + 两级嵌套达标倾向分类器`，特征数为 `89`。具体模型为非线性树提升模型：`GradientBoostingRegressor(loss="quantile")` 分别训练 Q05/Q10/Q50/Q90，`HistGradientBoostingClassifier` 输出近达标/达标工况倾向分数，尾部样本再训练局部低 CO 分位数模型并通过 `Pr_low` 融合。测试集 Q50 口径 RMSE 为 `514.718` mg/m^3，R2 为 `-1.142`；严格达标样本在测试集中占 `0.00%`。因此第三问不把模型输出当成现场实测判定，而是把第二问预测器输出放进规划器，由 Q50、Q90、达标工况倾向分数、温度增量联动和工程可执行性共同决定推荐方案。保留历史 CO 作为状态变量，使用当前过程变量和负压调节量预测 300s 后单点 CO；Q10_point<=2700 只作为低排放潜力指标，窗口中位数只作为稳定性风险诊断。

温度联动采用第一问当前温度模型 `当前第一问pressure-only特征 + Ridge_alpha10温度增量兼容层` 的增量口径：

```text
ΔT = T_q1(方案负压) - T_q1(控制时刻实际负压P0)
T_scenario = T_q2_current + ΔT
```

需要强调的是，该温度联动只是“负压方案对应的温度增量修正”，不是完整动态闭环控制。烧结温度本身有明显时滞，负压调整后温度不会瞬间变化，不同风箱的温度响应时间也不一致；题目也明确强调烧结过程多变量耦合、非线性强、时滞明显。因此当前温度联动还缺少两层动态传递：第一，`ΔP -> ΔT` 的分风箱时滞响应；第二，`ΔT -> CO` 的连续传递过程。本文只把 `ΔT` 作为候选方案的热状态一致性修正和风险诊断，不把它解释为“调压后温度立刻变化并立即影响 CO”的闭环仿真。

## 6. 主模型：分层低排放优化与滚动调控

主模型的决策变量为 18 个风箱负压强度 `P=(P1,...,P18)`。静态评分部分使用 P05-P95 范围寻找低排放倾向组合，但最终执行建议改为滚动调控：在最新 `300` s 窗口内逐点求解，后一时刻以上一时刻目标负压作为调节参考，避免一次性跳到静态组合。滚动窗口取 `300` s，是为了匹配第二问风箱负压/温度接近 300 s 的主导时滞，而不是用 30 s 短窗即时评估。

第二问配准方向是“过去风箱负压/温度 -> 当前 CO”。第三问调控方向必须解释为“当前调风箱负压 -> 约 `300` s 后的 CO”。因此滚动回测中，每个目标 CO 时刻都回推约 `300` s 作为控制时刻，把该控制时刻的负压作为基准，再把调控方案写入未来 CO 模型所需的滞后风箱特征。主目标回到单点 `CO(t+300s)`；未来 `300` s 窗口中位数只用于稳定性诊断。

本版先检查训练集中 `single_point_pass` 正样本数：若不少于 20，`Pr_pass_like` 进入规划筛选；若不足，则倾向项只作为诊断输出。规划层不再把 Q10 当作硬约束，而是用三层筛选候选：中位预测达标、风险上界不劣于基准、达标工况倾向分数达到阈值。

```text
first: mark candidates by engineering guardrails
gate: 接近达标工况层
layer 1: Q50_CO(P) <= 2800
layer 2: Q90_CO(P) <= Q90_CO(P0)
layer 3: Pr_pass_like(P) >= 0.35
indicator: Q10_CO(P) <= 2700
scheme A: control case, minimize Q50_CO(P), but not recommended if Q90 worsens
scheme B: main recommendation, minimize Q90_CO(P) under the same planning screen
```

本次规划状态为 `接近达标工况层_按Q50优化但未完全达成中位目标_需继续工况调整`。控制时刻 `t` 的实际 CO 为 `2781.756` mg/m^3，目标时刻 `t+300s` 的实际 CO 为 `2515.191` mg/m^3；控制时刻基准工况下 Q10/Q50/Q90 分别为 `2527.845`、`2595.886`、`2910.814` mg/m^3。方案 A 的 Q10/Q50/Q90 分别为 `2464.480`、`2571.370`、`2947.603` mg/m^3，`ΔQ50=-24.516`、`ΔQ90=36.789`；它虽然压低 Q50，但 Q90 高于基准，不满足风险不恶化要求，因此作为对照方案。方案 B 的 Q10/Q50/Q90 分别为 `2511.350`、`2626.850`、`2890.220` mg/m^3，虽然 Q50 较基准升高 `30.962` mg/m^3，但仍低于 2800，且 Q90 较基准降低 `20.590` mg/m^3，同时满足 Q50、Q90 和达标工况倾向筛选，因此定为主推荐方案。这些数值是规划器对 `CO(t+300s)` 的预测口径，不与控制时刻实测 CO 混用。

## 7. 辅助模型：当前工况平稳调控

辅助模型保留工程平稳保护项。需要说明的是，这些保护项是为了让推荐值更接近现场可执行动作，并不是题目给定的硬性数学约束；如果现场允许更大调节，下面四类约束都可以放宽、转为软惩罚，甚至在探索性方案中关闭：

```text
|P_i - P_i^0| <= 单箱最大调节量
sum_i |P_i - P_i^0| <= 总调节预算
|P_i - P_(i-1)| <= 相邻风箱差值约束
|ΔT_i| <= 温度变化约束
```

其中 `Delta_i` 按历史 P10-P90 宽度的 35% 估计，并限制在 `[0.10, 1.20]`；`d_i` 取相邻风箱历史强度差 P90；`B=0.45*sum(Delta_i)`。本文默认把这些项写入方案 A/B/C 的可执行性标记和排序，是出于工程稳健性考虑；它们不应被表述为题目天然要求。若放开单箱最大调节量、总调节预算、相邻风箱差值或温度变化约束，搜索空间会变大，预测 CO 可能进一步降低，但推荐值的现场平稳性和热状态风险也会相应增加。

## 10. 补充说明

- 主模型保留当前 CO 和历史 CO 作为短期状态变量，但不再用 `当前CO + ΔCO` 判断是否达标；模型直接学习 `CO(t+300s)` 单点的 `Q10/Q50/Q90` 分位数达标潜力，未来窗口中位数仅作为稳定性诊断。
- 历史达标样本改为原始单点 CO≤2800，低 CO 浓度不剔除；当前历史单点达标样本为 `71` 条。原“第二问修正CO≤2800且非异常、非孤立低谷”的严格可信口径保留为对照，不再覆盖主目标。
